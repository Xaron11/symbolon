# Third-party components

Release artifacts bundle no third-party tools. Rust and npm dependencies are linked or bundled under their own licenses; the allowed set is enforced by `deny.toml` (`cargo deny check licenses`) and the `license-check` script in `crates/symbolon-app/ui/package.json`.

Any tool redistributed in a release (for example Android `platform-tools`) must have a license that permits redistribution and must be listed here with its license and source.
