# Badge

A small count or status marker, such as the number of rows in a tab.

**Anatomy:** flat: a rounded tint with no border, an optional small icon and the text, so a badge never looks like a button.

**Tones:** `neutral` (default), `accent`, `error`, `warning`, `success`, `info`; status tones use the `status.*` colors.

**Typography:** the interface font at small size.

**Accessibility:** not a live region; when a count changes in a way the user must hear, announce one short message elsewhere instead.
