# Checkbox

An on/off choice that takes effect when a form or dialog is confirmed.

**Anatomy:** box (accent-colored when checked), label to its right; the whole row is clickable. An optional `description` sits under the label in small muted text, outside the label so it is the checkbox's description, not part of its name.

**States:** checked, unchecked, disabled.

**Keyboard:** Tab focuses; Space toggles.

**Accessibility:** a native checkbox with its label. For settings that apply immediately, use [Switch](switch.md).
