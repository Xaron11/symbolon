# IconButton

A button that shows only an icon, for compact toolbars and rows.

**Anatomy:** one icon, centered in a square of `control.height.md` (or `sm`); icons use `icon.size.md` (or `sm`).

**Variants:** `ghost` (default), `secondary` (base surface with a border), `danger`.

**States:** as [Button](button.md).

**Keyboard:** Tab focuses; Enter or Space activates.

**Accessibility:** a label is required. It becomes the accessible name and the native hover tooltip; the icon is hidden from assistive technology.
