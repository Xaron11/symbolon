# Row details

A side panel with what each side holds for one comparison row.

**Anatomy:** the row's path in monospace as its heading, a close button, the category chip, a note when equality is only assumed (fast mode: "Equal by size and time only; not verified."), then per side: the side's label, the path within the location, the size (or the kind for folders and links) and modified time, and the hash state (Not hashed, Partly hashed, Verified) with the first 12 hex digits of the digest.

**Keyboard:** Escape closes it, as does the close button.

**Accessibility:** a complementary landmark named after the row's path; the per-side facts are a description list.
