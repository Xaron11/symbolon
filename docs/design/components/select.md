# Select

Picks one value from a short fixed list, such as a hash algorithm.

**Anatomy:** visible label; trigger showing the current choice and a chevron; floating list box of options, the current one marked.

**Keyboard:** Enter, Space or ↓ opens the list; ↑/↓ move; Enter chooses; Escape closes; typing jumps to a matching option.

**Accessibility:** the trigger is a `combobox` named by the label; the list is a `listbox` of `option`s. For long or searchable lists, use [Combobox](combobox.md).
