# Tabs

Switches between views of the same subject, such as a comparison's summary and file list.

**Anatomy:** tab list with a bottom border; each tab is text, the selected one in the primary text color with a `border.width.strong` accent underline; the panel below.

**Keyboard:** Tab moves into the tab list onto the selected tab; ←/→ move between tabs and select them; Tab moves on into the panel.

**Accessibility:** `tablist` (named), `tab` with `aria-selected`, `tabpanel` labelled by its tab.
