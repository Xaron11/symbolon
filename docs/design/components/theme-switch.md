# ThemeSwitch

Chooses the theme: System (follow the OS), Dark or Light. A [Select](select.md) labelled "Theme", at the bottom of the expanded sidebar; the command palette offers the same three choices.

**Behaviour:** the choice applies at once and is remembered. A remembered Dark or Light theme is applied before the first paint, so starting the app never flashes the OS theme first. If storage is unavailable the choice still applies until the app closes.

**Accessibility:** as [Select](select.md).
