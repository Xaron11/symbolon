# API reference

The Rust API documentation is generated by rustdoc and published next to this book:

- [`symbolon_core`](../api/symbolon_core/index.html): the library; start here.
- [`symbolon_app`](../api/symbolon_app/index.html): Tauri backend commands.

Locally, `just docs-serve` serves the book and the API reference together with live reload (run `just docs-api` again after changing doc comments); `cargo doc --workspace --no-deps --open` opens the API reference alone. The binaries (`symbolon`, `symbolon-agent`) are documented by their `--help` output; a command-line chapter follows with the CLI in M3.
