# API reference

The Rust API documentation is generated by rustdoc and published next to this book. It includes private items (marked with a lock), because its readers are contributors: the binaries and the app keep almost everything private.

| Crate                                                | What it documents                                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| [`symbolon_core`](../api/symbolon_core/index.html)   | The library with all the logic; start here.                                                       |
| [`symbolon_app`](../api/symbolon_app/index.html)     | The Tauri backend: commands, the DTOs the UI receives and the state kept between commands.        |
| [`symbolon`](../api/symbolon/index.html)             | The command-line client, crate `symbolon-cli`. Usage is in the [command-line chapter](../cli.md). |
| [`symbolon_agent`](../api/symbolon_agent/index.html) | The scanner pushed to Android phones ([ADR-0017](../adr/0017-android-over-adb.md)).               |

`symbolon_core`'s modules:

- [`scan`](../api/symbolon_core/scan/index.html): list a location, store its entries and hash file contents.
- [`compare`](../api/symbolon_core/compare/index.html): compare two or more locations.
- [`query`](../api/symbolon_core/query/index.html): read-only access to the catalog, also while scans write.
- [`catalog`](../api/symbolon_core/catalog/index.html): the SQLite database of locations, scans and entries.
- [`pathkey`](../api/symbolon_core/pathkey/index.html): lossless relative paths and their matching keys.
- [`hash`](../api/symbolon_core/hash/index.html): hash algorithms, full and partial digests.
- [`identity`](../api/symbolon_core/identity/index.html): device fingerprints.
- [`source`](../api/symbolon_core/source/index.html): where a location's files are listed and read from.
- [`transport`](../api/symbolon_core/transport/index.html): connections to devices without a local filesystem.
- [`agent`](../api/symbolon_core/agent/index.html): the protocol between the host and the on-device agent.

Locally, `just docs-serve` serves the book and the API reference together with live reload (run `just docs-api` again after changing doc comments).
