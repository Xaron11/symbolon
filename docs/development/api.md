# API reference

The Rust API documentation is generated by rustdoc and published next to this book:

- [`symbolon_core`](../api/symbolon_core/index.html): the library; start here.
- [`symbolon_app`](../api/symbolon_app/index.html): Tauri backend commands.

Build it locally with `just docs` (book and API) or `cargo doc --workspace --no-deps --open` (API only). The binaries (`symbolon`, `symbolon-agent`) are documented by their `--help` output; a command-line chapter follows with the CLI in M3.
